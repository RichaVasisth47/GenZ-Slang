# GenZ-Slang Flashcard App 💬🔥

An interactive flashcard application built with Python and Tkinter that helps users learn and master popular Gen-Z slang words and their meanings!

## Features
* Clean and user-friendly GUI built using Tkinter.
* Interactive flashcard flipping mechanism to reveal definitions.
* Perfect blend of modern terminology and practical desktop app development.
